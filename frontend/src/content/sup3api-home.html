接入之前

已有 OpenAI 或 Claude 客户端可以使用吗？

可以按对应协议配置服务地址和 Sup3API 密钥。OpenAI SDK 的 base_url 使用本站根地址加 /v1；Anthropic SDK 使用根地址。模型和功能支持取决于实际配置，详见 API 文档。

三维生成如何返回模型文件？

创建请求返回任务 ID。任务成功且资产交付就绪后，从 artifacts 下载模型、贴图等文件；steps[].provider_result 保留各阶段的供应商原始查询结果。

如何先测试连接？

在 API 接入页查询模型或资产能力，并对三维请求执行「校验与估价」。这些诊断操作不会创建生成任务。实际生成调用会按已开通的服务计费。
