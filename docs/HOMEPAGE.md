# 首页交互与验收

首页由 Vue 组件渲染，保留浅绿色三角网格 Logo，使用深色背景、薄荷绿三维形态和浅色能力区。此次修改限于首页、旧首页入口与文档；不修改后端、供应商调用、认证或计费。

## 交互约定

参考 Apple 的 [Motion](https://developer.apple.com/design/human-interface-guidelines/motion) 与 [Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility) 指南：

- 动效可暂停；减少动态效果偏好默认关闭自动旋转。离屏、后台和卸载时停止绘制。
- 模型支持拖动、方向键、左右按钮与重置，保留手机纵向滚动。
- 按钮至少 44 × 44 CSS 像素；键盘焦点可见，标签支持方向键及 Home/End。
- 手机菜单支持 Escape 关闭并恢复焦点；页面使用原生滚动与浏览器历史。
- 复制显示成功或失败状态；示例复用 API 文档定义，不提交生成任务。

## 验证结果

- 首页 8 项、模型交互 9 项测试通过；客户门户 4 项、密钥管理 27 项、标题 12 项、语言键完整性 3 项回归通过，共 63 项。
- TypeScript、针对变更文件的 ESLint、Vite 正式构建、Go embed 构建、静态文档同步及无生成费用的烟测通过。
- Chromium 实际检查 320、390、768、1440 像素布局，无页面横向溢出。检查了菜单、键盘切换、原生代码复制、模型拖动与重置、FAQ 展开、接入页往返以及两个旧首页地址重定向。
- 最终正式首页 axe 扫描通过 35 条规则，未发现违规；三组能力/代码切换组合也未发现违规。扫描不等同于完整无障碍认证。
- 本机模型绘制采样：550 × 500 CSS 像素、DPR 2，60 次采样中位数 8.2 ms、P95 11.3 ms；自动旋转限制为约 30 fps。此数据不是所有设备的性能保证。

触摸方向判断和取消由组件测试覆盖；未进行实体 iPhone 或 Safari 验收。复现命令见 [测试指南](TESTING.md)。
